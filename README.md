built for directors.

- Drop an image or prompt to generate a multi-cam shot grid

- Edit any shot and let the whole board update automatically
- Render with 11+ models while keeping the same visual DNA

## Director Canvas

**From storyboard to motion.**

The Director Canvas turns your locked storyboard into animated shots. Open a
panel, move the camera, adjust light, and generate — all while the characters
and locations stay consistent.

- Open any shot from the storyboard on the canvas
- Drag the camera cube to set angle, tilt and motion
- Tune key light, temperature and rim light in real time
- Render with any of 11+ models and export 4K clips

## Creative Tools

**A ComfyUI-simple canvas, for directors.**

Three connected tools that mirror a real director's workflow: plan the
storyboard, move the camera, then light the scene. Each step feeds the next
like a node graph, without the complexity.

1. **Storyboard Creator** — Drop an image or prompt and get a multi-cam
   storyboard. Every character, object, and location is locked so your shots
   stay consistent.
2. **Multi-angle Camera Control** — Precisely control camera movement with a
   draggable cube for custom lens texture and motion across each storyboard
   panel.
3. **Relighting in Real Time** — Reposition the key light, tune brightness and
   color temperature, and add a rim light to keep every shot mood-matched.

## Director Workflow

**Storyboard first, then shoot.**

1. **Drop a prompt or image** — The AI turns it into a detailed multi-cam
   storyboard, like a simplified ComfyUI node flow.
2. **Lock consistency** — Characters, objects, locations, and props are tagged
   and locked across every shot so nothing drifts between scenes.
3. **Direct camera & light** — Open any shot in the Director Canvas, drag the
   camera cube, and tune key light to match the mood.
4. **Render with any model** — Pick the best engine from 11+ models and export
   consistent 4K clips, all from the same storyboard.
